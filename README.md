  <h1>Visual Question Answering (VQA) with BLIP</h2>

  <p>A concise Jupyter Notebook demonstrating how to perform Visual Question Answering (VQA) using Salesforce's pre-trained blip-vqa-base model via the Hugging Face transformers library.

What it does:
Model Setup: Loads the BlipForQuestionAnswering model and AutoProcessor from Hugging Face.

Image Processing: Opens and prepares a local image (beach.jpg) using PIL.

Inference: Processes visual and text inputs to generate natural language answers to questions about the image.

Tech Stack:
Python, PyTorch, Hugging Face transformers, Pillow (PIL).</p>
